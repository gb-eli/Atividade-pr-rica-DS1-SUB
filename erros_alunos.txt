STATUS: IMPORTA SEM ERRO, MAS TEM BUG LÓGICO
------------------------------------------

Linha 19: elif roupa == b"4":
  - "b"4"" é um literal de bytes (bytes), mas "roupa" é uma string (str).
  - A comparação str == bytes nunca é True em Python 3.
  - A opção "4 - sim" (sair) nunca vai funcionar.
  - Correção: trocar b"4" por "4"

OBSERVAÇÃO: O diego.py foi incluído no main.py pois o Python consegue importá-lo
sem erros. Apenas a opção 4 não vai responder ao usuário.
